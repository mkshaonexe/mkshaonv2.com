# Product Requirements Document (PRD)
## Personal Portfolio & Blog Website for MK Shaon

---

## 1. Executive Summary

### 1.1 Product Vision
Create a professional, monetizable personal portfolio and blog website that showcases MK Shaon's identity as a content creator, developer, and technology enthusiast. The website will feature a unique social media-inspired homepage, professional blog section, and comprehensive about page while being optimized for Google AdSense monetization.

### 1.2 Target Audience
- Technology enthusiasts
- Potential collaborators and clients
- YouTube and Facebook followers
- Fellow developers and students
- Recruiters and educational institutions

### 1.3 Business Goals
- Establish professional online presence
- Monetize through Google AdSense
- Drive traffic from social media channels
- Showcase technical skills and projects
- Build authority in tech/AI space

**Light Theme (Alternative):**

### 5.2 Typography

**Font Families:**
- **Headings:** 'Inter', 'SF Pro Display', -apple-system, sans-serif
- **Body:** 'Inter', 'SF Pro Text', -apple-system, sans-serif
- **Code:** 'Fira Code', 'JetBrains Mono', 'Courier New', monospace

**Type Scale:**
- H1: 48px (bold, line-height: 1.1)
- H2: 36px (bold, line-height: 1.2)
- H3: 28px (semibold, line-height: 1.3)
- H4: 24px (semibold, line-height: 1.4)
- H5: 20px (medium, line-height: 1.5)
- Body Large: 18px (regular, line-height: 1.7)
- Body: 16px (regular, line-height: 1.6)
- Body Small: 14px (regular, line-height: 1.5)
- Caption: 12px (regular, line-height: 1.4)

### 5.3 Spacing System
- Base unit: 8px
- Scale: 4px, 8px, 12px, 16px, 24px, 32px, 48px, 64px, 96px

### 5.4 Border Radius
- Small: 4px (buttons, inputs)
- Medium: 8px (cards)
- Large: 12px (modals, featured cards)
- XLarge: 16px (hero sections)
- Round: 50% (avatars, icons)

### 5.5 Shadows
- Small: 0 1px 3px rgba(0,0,0,0.12)
- Medium: 0 4px 6px rgba(0,0,0,0.16)
- Large: 0 10px 25px rgba(0,0,0,0.20)
- Glow: 0 0 20px rgba(0,217,255,0.3)

### 5.6 Animations & Transitions
- Duration: 200ms (fast), 300ms (normal), 500ms (slow)
- Easing: ease-in-out, cubic-bezier(0.4, 0, 0.2, 1)
- Hover effects: translate, scale, opacity, shadow
- Page transitions: fade, slide

## 7. Technical Requirements

### 7.1 Technology Stack Recommendations

**Frontend:**
- Framework: Next.js 14+ (React)
- Styling: Tailwind CSS + CSS Modules
- Animation: Framer Motion
- Icons: React Icons or Heroicons
- State Management: React Context / Zustand

**Backend/CMS:**
- Option 1: Next.js API Routes + MDX for blog
- Option 2: Headless CMS (Contentful, Sanity, or Strapi)
- Option 3: WordPress REST API

**Database:**
- PostgreSQL or MongoDB (for comments, analytics)
- Or Firebase/Supabase for simpler setup

**Hosting:**
- Vercel (recommended for Next.js)
- Alternative: Netlify, AWS Amplify

**Domain:**
- mkshaon.com

### 7.2 Performance Requirements
- **Page Load Time:** < 3 seconds (desktop), < 4 seconds (mobile)
- **First Contentful Paint (FCP):** < 1.5 seconds
- **Time to Interactive (TTI):** < 3.5 seconds
- **Lighthouse Score:** 90+ (all categories)
- **Core Web Vitals:**
  - LCP (Largest Contentful Paint): < 2.5s
  - FID (First Input Delay): < 100ms
  - CLS (Cumulative Layout Shift): < 0.1

### 7.3 SEO Requirements

**Technical SEO:**
- Semantic HTML5 markup
- Proper heading hierarchy (H1 → H2 → H3)
- Meta tags (title, description, keywords)
- Open Graph tags (Facebook, LinkedIn)
- Twitter Card tags
- Canonical URLs
- XML sitemap
- Robots.txt
- Structured data (JSON-LD):
  - Person schema (homepage)
  - Article schema (blog posts)
  - BreadcrumbList schema
- Alt text for all images
- Clean URL structure (no special characters)

**Content SEO:**
- Target keyword research and optimization
- Internal linking strategy
- External linking to authoritative sources
- Image optimization (alt text, compression)
- Mobile-friendly design

**Blog-Specific SEO:**
- Category and tag taxonomy
- Related posts suggestions
- Author bio with schema markup
- Publish and updated dates
- Reading time
- Social sharing functionality

### 7.4 Google AdSense Integration

**Ad Placement Strategy:**

**Homepage:**
- Top banner (728x90 leaderboard - desktop)
- Right sidebar (300x250 medium rectangle)
- In-feed ad (between sections)
- Bottom banner (728x90 leaderboard)

**Blog Listing:**
